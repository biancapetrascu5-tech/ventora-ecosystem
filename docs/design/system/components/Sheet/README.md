# Sheet

The working surface: a `sheet` panel with a hairline edge on the `canvas`, holding forms, settings and content; SheetSection splits it with a heading.

**Sheet props.** `padded` (default true), `as`. **SheetSection props.** `title`, `description`, `actions`, `children`. Sections are separated by a hairline and `space-8`, never by coloured bands or extra cards. Edge to edge under 640px.
