# HubLauncher

The launcher: greeting and the day's sentence, "Aplicațiile tale" (tiles; an icon grid on phones), "Alte aplicații Ventora" with the reason and action for each, and the AppLaunch transition when you open an app (click a tile in the preview).

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

"Alte aplicații Ventora" can carry one catalog recommendation — a commercial slot, only for owners and admins, with "Nu mă interesează", the remind menu and the global caps, never a fixed part of the screen (Marketing here), and the section ends with "Vezi toate aplicațiile Ventora", which opens HubCatalog.

After the product review: the day's sentence links to the work (programări → Booking · Azi, facturi → Finance, concediu → HR); "Reordonează" lets each person order their apps (fixed order by default); "Alte aplicații Ventora" are compact rows; tab order goes through your apps before the commercial slot.
