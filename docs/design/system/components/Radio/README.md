# Radio

One choice from a small set, all options visible; use RadioGroup, which renders the fieldset, legend and error.

**RadioGroup props.** `legend`, `options` `[{ value, label, description?, disabled? }]`, `value` / `defaultValue` / `onChange`, `orientation` (`vertical` default, `horizontal` for two or three short options), `required`, `error`, `helper`, `disabled`.

Prefer SegmentedControl for switching a view, Select for more than five options.
