# GrowthCampaigns

Campaigns list: mode (automatic on a signal, or scheduled), offer, slots, disturbance rate and status. A campaign above the 5% disturbance threshold stops by itself.

**Texts (S136).** The screen's texts are in `i18n/founder-growth.json`: `founder.growth.campaigns.*`, plus the shared `founder.growth.common.*`. Romanian only for now. Translations of offer and campaign texts are managed in FounderTranslations.
