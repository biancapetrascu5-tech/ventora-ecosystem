# CommercialPreferences

Account settings → Notifications → "Recomandări Ventora Systems": in-app recommendations on or off; e-mail switched off and locked with "Disponibil în curând"; and a note that messages about the account's limits stay on, because they are account information, not recommendations. Part of HubAccount.

**Texts (S136).** In `i18n/commercial.json`, in the 6 languages: `prefs.*` (title, description, in the app, by e-mail, the account-limits notice). The library keeps its own copy in `S`; the file is what the apps load.
