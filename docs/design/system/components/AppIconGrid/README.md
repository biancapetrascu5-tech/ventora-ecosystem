# AppIconGrid

The construction grid of the app-icon family: 48 × 48 units, plate corners r12, keyline square 10–38 and keyline circle r15, diagonals that align the V facets, gaps of 2–2.5 units and details of at least 2.5 units (≥1px at 24px). Every new app icon is drawn on this grid, with filled geometric shapes in off-white and exactly one peach part.
