# PilotFeedback

The test / pilot account (S140). Romanian only for now; keys `onboarding.pilot.*` in `i18n/onboarding.json`.

**The band**, discreet, at the top of every app for the test salon: "Folosești Ventora Systems în perioada de test. Spune-ne ce nu merge: citim tot." (shorter on phones) with "Trimite o părere".

**The feedback form** (Dialog): what it is about (something doesn't work, an idea, a question), what happened (required), an optional screenshot, "Mă puteți suna dacă e nevoie"; the screen, app and device are attached automatically, never client data. Sent: a Toast ("Îți scriem în cel mult o zi lucrătoare"); it arrives as a support request.

Shown at 1280, 820 and 390, light and dark.
