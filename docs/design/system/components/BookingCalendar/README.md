# BookingCalendar

EasyBook — Calendar with Schedule: resources (one column per person), week (today marked, Sunday closed) and day (pick the person). Date navigation, "Azi" and the view switch sit above the grid; the grid scrolls inside itself.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

After the product review: "Primul loc liber" jumps to the next free slot for the chosen service ("Următorul loc liber: joi, 14:30, la Ioana."); on touch screens moving is done from the detail too; the grid can be walked with the keyboard.

**S126 (B.9, B.10).** Bookings with several services ("1/3", "2/3"), class sessions ("8/10") and the location picker, drawn in BookingMultiService, BookingClasses and BookingLocations.
