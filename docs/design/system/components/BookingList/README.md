# BookingList

EasyBook — the appointments list: search, period, person and status filters with removable filter pills, sorting, selection with the bulk bar (confirm, send reminder, cancel), row actions, pagination. On tablets the person and price columns hide (optional columns); on phones rows become a list.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

After the product review: when the search finds nothing in the filtered period but finds something elsewhere, it says "{n} rezultate în alte zile" with a link; the export uses the active filters and says so; filters are remembered per person.
