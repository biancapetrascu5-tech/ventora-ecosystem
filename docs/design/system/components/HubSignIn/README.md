# HubSignIn

Sign-in, invitation only: e-mail, password with "Ai uitat parola?", remember me, language selector, and the note that accounts are created by invitation. No "Creează cont". The phone/dark frame shows the error state (Notice + invalid field).

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

After the product review: fields use `autocomplete` (`username`, `current-password`) and Enter submits; the error state offers "Ai uitat parola?" right in the message; "Ține-mă minte pe acest dispozitiv timp de 30 de zile" is unticked by default; the error is announced and focus returns to the first wrong field.
