# Icon

Lucide icons, inlined — the only interface icon set; no emoji anywhere.

**Props.** `name` (Lucide name), `size` (16 in controls, 20 in navigation, 24 large), `strokeWidth` (1.75 default, for precision at small sizes), `label` (only when the icon carries meaning on its own; otherwise it is hidden from screen readers). The bundle ships the icons shown here; add others from the same Lucide release (0.460.0) rather than mixing sets.
