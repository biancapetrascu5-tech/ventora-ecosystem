# AnalyticsDashboard

Analytics — Overview: four Stat tiles with change against last year, revenue per month over 12 months (grey comparison, October still running in peach), revenue by service as ranked bars and appointments by weekday with last year next to them. Period and comparison controls sit in the page header.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

Percentage-point changes read "+3 pp" on screen and "plus 3 puncte procentuale" for screen readers and in tooltips (`delta.srValue`).
