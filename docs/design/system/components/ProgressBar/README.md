# ProgressBar

Progress of a task the user started (import, export, upload, setup).

**Props.** `value` (0–100; omit for indeterminate), `label`, `showValue`, `size` (`sm`, `md`, `lg`), `tone`. The fill is `primary` while running and turns `done-mark` (lime) at 100%. For consumption against a plan limit use UsageMeter.
