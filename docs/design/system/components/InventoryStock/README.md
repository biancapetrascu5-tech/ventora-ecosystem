# InventoryStock

StockDesk — Stock with alerts: a peach Notice that names what ran out and what depends on it, with "Pregătește comanda"; each product's stock as a number and a small bar with the minimum marked; "Sub minim" peach, "Epuizat" red, "Comandat" neutral; "Doar ce trebuie comandat" filters the list.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

The link between stock and appointments is the optional EasyBook ↔ StockDesk integration for consumables; that sentence appears only when the business has both apps.
