# BookingStates

The states that complete the Booking screens, with the approved copy: empty day, nothing that needs you, loading error, appointment marked done (with undo); first-use hint in the calendar; empty list with and without filters, export ready; bulk and single cancellation dialogs (the client message is mentioned only when the business has the notification on); "Marchează: nu a venit" and a successful move; validation and overlap in the new-appointment form, appointment saved; settings saved, unsaved changes; owner notified at the limit. Light and dark.
