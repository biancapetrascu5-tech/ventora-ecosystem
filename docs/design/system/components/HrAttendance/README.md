# HrAttendance

HR — Attendance: who is at work now (peach, the only "now"), lateness this week, leave, hours worked; "Au nevoie de tine" (leave to approve, a missing clock-out to correct) above the week table, because the table needs the full width. Monday and Tuesday hide on tablets; on phones each person shows today and the week total.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

Lateness reads neutral and factual: the entry time, then "Întârziere · 12 min" in `attention-ink`.
