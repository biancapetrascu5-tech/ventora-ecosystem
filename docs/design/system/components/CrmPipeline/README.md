# CrmPipeline

ClientDesk — Pipeline: open opportunities by stage with each stage's value, the next step on every card (peach only when it is today or overdue), "Câștigate în octombrie" with the lime check. Moving a card works from its menu. On phones one stage at a time, picked from the stage chips.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

Stages are chosen by each business ("Editează etapele"), starting from a default set: Contact nou, Ofertă trimisă, Negociere, Câștigate, Pierdute.
