# Badge

Counts and very short labels: unread counts, "Nou", plan tier.

**Props.** `count` (formatted, capped at `max` → "99+"), `children` (a label), `dot`, `tone` (`neutral`, `attention` — unread / needs you, `primary`), `label` (accessible text such as "3 necitite"). A count that does not ask for action stays `neutral`.
