# HubAppTexts

The texts of the 15 apps (S116, point 4): the name (no "Ventora" in front), the catalog's short description and the "Vezi detaliile" description, in the 6 languages. Keys `apps.{id}.name`, `apps.{id}.short`, `apps.{id}.details` and `apps.seeDetails` in `i18n/apps.json`.

**Rules.** Names are the same in every language (EasyBook, ClientDesk, DocSpace, ContractDesk, EventSpace, TeamSpace, StockDesk, ShiftPlan, CampaignKit, DataView, AssetDesk, TaskBoard, MoneyDesk, Portal, Network). The short description is one line, nouns, no full stop (AppTile, HubCatalog, the launcher). The details are 2–3 sentences that say what the business does with it; client-facing nuance stays out.

Shown in AppTile tiles and in the "Vezi detaliile" panel, for each language, plus phone frames.

**S147.** Descrierile scurte (`apps.*.short`) pentru cele 13 aplicații și Network sunt cele din 13.11, în 6 limbi.
