# Checkbox

An independent yes/no choice, or one of several in a list; supports `indeterminate` for "select all" headers.

**Props.** `label`, `description`, `checked` / `defaultChecked` / `onChange(checked)`, `indeterminate`, `invalid`, `disabled`. Without a visible label pass `aria-label`.

**Checked** fills with `primary`. The hit area is 20px around a 16px box on desktop and grows with the row on mobile.
