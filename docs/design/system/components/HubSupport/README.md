# HubSupport

Support: "Solicitările mele" with states (new reply in peach, solved in lime) and a new-request form ("Solicitare nouă"). Two panes on desktop, stacked on tablet; on phones the list and the form are separate screens.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

After the product review: the app is filled in from the page you came from; "Mă blochează" is explained. Help-article suggestions wait for the help centre.
