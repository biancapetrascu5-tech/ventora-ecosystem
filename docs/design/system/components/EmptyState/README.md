# EmptyState

What a screen shows when there is nothing to show: one Lucide icon in a quiet plate, a title, one sentence, the next action — no illustrations.

**Props.** `icon`, `title`, `description`, `actions`, `size` (`md`, `sm` inside panels and tables).

**Three kinds.** First use ("Nicio programare azi" + "Creează programare"), no results ("Niciun rezultat pentru „Ionescu”" + "Șterge filtrele"), error ("Nu am putut încărca lista" + "Încearcă din nou" and "Scrie-ne"). For missing access use the AppTile reasons, not an EmptyState.
