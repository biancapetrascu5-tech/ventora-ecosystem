# StatusDot

A small mark beside a label for live or presence state ("Acum, în cabinetul 2", "Offline").

**Props.** `tone` (`attention`, `done`, `danger`, `neutral`, `offline` — a hollow ring), `label` (required for meaning), `hideLabel` (keeps it for screen readers only, e.g. inside an Avatar). Use StatusPill when the state is the main information of a cell.
