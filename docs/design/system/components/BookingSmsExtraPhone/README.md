# BookingSmsExtraPhone

EasyBook — the extra phone (SPEC_ECRANE_SMS §6): "Conectează alt telefon" when the phone included in the plan is already connected opens the existing UpgradeDialog with one add-on option, "Un telefon în plus". Only when the person acts — no proactive recommendation in the MVP. Built only from UpgradeDialog (options, confirm, processing, success, error; member variant with "Recomandă"), Sheet, SheetSection, Button and the §1 phone rows.

Shown at 1280, 820 and 390 over the Settings page, every step in light and dark, desktop and phone (bottom sheet), and a German (desktop) and Italian (390, admin) label test.

**The option.** "Un telefon în plus" · "{preț} lei pe lună · fără cost de implementare" (S15; the price is still to be filled in, D-SMS-4) · what it does: the reminders are shared between phones and leave sooner, about 80 messages per hour with two phones, and "Fiecare client primește mesajele de pe același număr, de obicei. Dacă un telefon se deconectează, unele pot pleca de pe celălalt." (D-SMS-11).

**Steps.** Options → confirmation of the payment as a separate step (what, when, price, setup cost, total today, card) → processing → success ("Conectează telefonul" opens §2) → error (the bank's reason, "Încearcă din nou", "Folosește alt card").

**Roles (S12, S18).** Only the owner pays. Admin and the EasyBook manager see the option, its price, who decides ("Ajunge la Bianca Petrașcu (proprietar).") and "Recomandă"; after it, the confirmation. The manager reaches it from the capacity notice. Members don't have "Conectează alt telefon".

**After.** Settings show "Telefoanele afacerii" with both phones by name and the doubled capacity: "Poți trimite aproximativ 80 de mesaje pe oră de pe cele două telefoane." and "Reamintirile se împart între ele. Dacă unul se deconectează, celălalt trimite mesajele care încă așteaptă." (D-SMS-11).

**Colour.** No peach anywhere in this flow: the options step has no counter, and the success counter ("Telefoane conectate 1 → 2") is neutral (S50). Peach stays for the disconnected phone.
