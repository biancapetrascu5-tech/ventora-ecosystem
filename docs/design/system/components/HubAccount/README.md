# HubAccount

Account settings in the Hub shell: profile, preferences (theme, language), notifications per channel, security (password, two-step sign-in, active sessions).

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

Notifications include the "Recomandări Ventora" section (see CommercialPreferences).

After the product review: on phones the page is a list of sections, each with its own page; theme and language apply at once. Two-step sign-in is mandatory for the owner, with 14 days' grace from the first sign-in, and recovery codes ("Coduri de recuperare").
