# BookingLimit

EasyBook — the monthly appointment limit reached when creating an appointment: existing ones stay editable; the owner buys more right there or requests a plan change; anyone else sees who can buy and can tell them. Dialog on desktop and tablet, bottom sheet on phones.

Shown at 1280 (desktop), 820 (tablet portrait) and 390 (phone), in light and dark, built only from the system's components.

After the product review: the limit opens the shared UpgradeDialog (pack first, then the plan request); the appointment being created is kept and saved after the purchase; members see the options and who decides.
