# Avatar

A person or business: photo, or initials on `avatar-bg`; AvatarGroup stacks several with a "+n" remainder.

**Avatar props.** `name` (required — accessible name and initials), `src`, `size` (`xs` 20, `sm` 24, `md` 32, `lg` 40, `xl` 56), `shape` (`circle` people, `square` businesses), `status` (a StatusDot tone).

**AvatarGroup props.** `people` `[{ name, src? }]`, `max`, `size`. The group's accessible name lists everyone.
