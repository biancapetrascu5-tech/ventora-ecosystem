# RecommendationLabel

The small neutral Badge "Recomandare" on anything commercial — RecommendationCard, a commercial DiscoveryTooltip, HubRecommendation, a recommended AppTile. Always the same, never peach (now / your attention), never lime (done). No props besides `className`.

**Texts (S136).** In `i18n/commercial.json`, in the 6 languages: `recommendation`, `fromTeam`. The library keeps its own copy in `S`; the file is what the apps load.
