# Tooltip

A short label for an icon-only control or a truncated value, on hover and keyboard focus (400ms delay); never essential information.

**Props.** `content`, `shortcut` (Kbd keys, e.g. `['mod','K']`), `placement` (`top-center` default, `bottom-center`, `right-start`…), `delay`, `open` (controlled, for docs). Wrap exactly one focusable child. Esc dismisses. Inverted colours (`tooltip-bg` / `tooltip-ink`) so it reads in both themes.
