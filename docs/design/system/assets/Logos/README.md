# Logos

The official Ventora Systems logo files, used exactly as supplied. Full colour (peach, copper, off-white facets on a navy diamond), not a single-ink mark: never recolour, redraw, retype or place them on a coloured plate.

- `ventora-logo.svg` — the logo for light backgrounds: the mark plus the "VENTORA SYSTEMS" wordmark on one line (the initials V and S in peach #FFAA75, the rest in navy #000C3F). 415 × 68.
- `ventora-logo-dark.svg` — the logo for dark backgrounds, variant B: lighter diamond (#3A4680), off-white wordmark (#F1EFEA), the initials V and S in peach. The facets are separated by transparent cuts (an SVG mask), so the ground shows through them on any dark surface. The mask id is unique per file.
- `ventora-logo-stacked.svg` / `ventora-logo-stacked-dark.svg` — on two lines: "VENTORA", and under it a smaller "SYSTEMS" (62%) centred under "VENTORA", for narrow places. 250 × 68.
- `ventora-logo-stacked-small.svg` / `ventora-logo-stacked-small-dark.svg` — on two lines with "SYSTEMS" at full size, left-aligned, for small sizes (under 32px mark height), where the smaller "SYSTEMS" would not be readable.
- `ventora-mark.svg` — the mark alone, light (no text, unchanged).
- `ventora-mark-dark.svg` — the mark alone, dark, variant B.
- `favicon.svg` — the mark; switches to variant B when the system is in dark mode.
- `ventora-logo-email-2x.png` — the light logo as PNG for e-mail headers, where SVG doesn't show everywhere: 537 × 88 px, transparent, for display at 268 × 44. Rendered from `ventora-logo.svg`.

The wordmark is part of the file (Montserrat ExtraBold, as drawn). Never set "Ventora Systems" in Syne (or any font) next to the mark in its place. Brand change of 1 Nov 2026: the visible name is "Ventora Systems"; "Ventora" alone no longer appears.
