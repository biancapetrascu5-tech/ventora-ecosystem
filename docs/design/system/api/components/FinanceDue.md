# FinanceDue

`page` · Ecrane aplicații · versiunea 1.0.1

MoneyDesk — Due and overdue: what is still to be collected, overdue (peach, with the oldest age), due in 7 days, collected this month with its change; "Au nevoie de tine" with the overdue invoices and their next action; the invoice list filterable into all, overdue, upcoming and paid. Overdue is peach, not red: a late invoice is a task, not an error.
