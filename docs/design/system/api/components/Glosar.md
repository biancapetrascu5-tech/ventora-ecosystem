# Glosar

`foundation` · Foundations · versiunea 1.0.2

The single list of terms for every screen, in the six languages, with the writing rules (who we talk to, tone, buttons, errors, active voice, names from data, plurals, numbers, diacritics, localisation). The same content is in `glossary.md` at the root. A new term goes into the glossary first, then into the screen.
