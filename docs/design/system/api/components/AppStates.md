# AppStates

`page` · Ecrane aplicații · versiunea 1.0.1

The states that complete the Stage 4 screens, with the approved copy: ClientDesk (empty pipeline, empty stage, moved, lost with an optional reason, stages chosen by the business), TeamSpace (leave approved, leave declined with a required reason, clock-out corrected, a week without entries, neutral lateness), StockDesk (empty stock, order prepared, stock adjusted, the optional EasyBook integration), TaskBoard (no tasks, launch at risk), MoneyDesk (no overdue invoices, marked paid, reminder sent, automatic reminders in settings), DataView (too little data, error, empty period, "+3 pp"). Light and dark.
