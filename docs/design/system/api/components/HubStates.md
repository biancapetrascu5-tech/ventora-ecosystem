# HubStates

`page` · Ecrane Hub · versiunea 1.0.1

The states that complete the Hub screens, with the approved copy: sign-in in progress, too many attempts, offline; invitation request sent, cancelled, already used; access requested and already requested; profile saved, save failed, password changed; stopping someone's access (danger dialog, "Oprește accesul" / "Renunță"); invitation sent; empty team and invitation lists; support request sent and no requests. Light and dark.
